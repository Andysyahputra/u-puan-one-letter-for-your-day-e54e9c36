One letter that captures the day. The day this entry was made is
Tuesday, 24 November 2026, so the letter is:

**T** — for Tuesday, for trying, for "told you so".

Tuesday is the day's own initial. "Trying" is what the day is made of:
another attempt, kept going after sixty-nine tries with no win yet.
And "told you so" is the day's dare — the bet that today, finally,
one of them lands.

## How it works

`main.ts` (Node 22, no dependencies) derives the letter from the fixed
day the entry was built on and writes exactly that one letter — A–Z,
nothing else — to `/output/entry.txt`.

```sh
node main.ts
cat /output/entry.txt   # T
```
